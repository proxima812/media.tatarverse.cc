# .agents

Инструкции для AI-агентов по этому репозиторию.

```
.agents/
  skills/
    starter-*/SKILL.md   скиллы стартера - едут вместе с репозиторием
    <прочие>/            установленные через `skills add` - в git не попадают
```

Иерархия: короткие глобальные правила в [`AGENTS.md`](../AGENTS.md) +
специализированные скиллы в `skills/starter-*/`.

Скиллы стартера описывают **правила стартера**, а не конкретный сайт.
Меняется архитектура - обновить соответствующий `SKILL.md` в том же коммите.

Установить сторонние скиллы:

```bash
bunx skills add <owner>/<repo>
```
