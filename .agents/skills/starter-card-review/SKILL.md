# Ревью карточки каталога

Карточки - основной поток контрибуций: github, формы (yandex, google),
просьбы авторов напрямую. Схема ловит опечатки в полях, но не ловит
неверную категорию, рекламный тон и отсутствие перевода до `check:i18n`.
Этот чеклист - то, что проверяет человек.

Источник истины по схеме - `src/content.config.ts`, по словарю категорий и
тегов - `src/components/Catalog/taxonomy.ts`. Если чеклист разошелся с
кодом, прав код.

## Файл и id

- Путь: `src/data/cards/<id>.md`, перевод - `src/data/cards-en/<id>.md`
  с тем же id.
- id - латиница, нижний регистр, дефисы, транслитерация названия плюс
  суффикс основной категории: `agidel-journal-media`, `arhiufa-channel`,
  `aydar-kalimullin-author`. Суффикс - именно основная категория, а не все
  из `categories`.
- Дубликаты: проверить, что проекта еще нет - по `url` и по имени.

  ```bash
  grep -rn "instagram.com/15_daqqa" src/data/cards/
  ```

## Фронтматтер русской карточки

| Поле | Требование |
|---|---|
| `name` | Как проект называет себя сам, без кавычек-описаний и без слова «канал» в конце, если оно не часть имени |
| `description` | Одно предложение: что это и для кого. Нейтрально, без «лучший», «уникальный», «must have» |
| `facts` | Ровно 3-4 факта. Проверяемые: год, аудитория, площадка, прошлый опыт. Не оценки |
| `url` | Рабочая ссылка на первоисточник (сам канал, сайт), не на агрегатор и не на репост |
| `pubDate` | Дата добавления в каталог, а не дата основания проекта |
| `logo` | Необязательно. Есть - лежит в `src/assets/images/logo/<id>.png`, путь в фронтматтере относительный: `../../assets/images/logo/<id>.png`. Нет логотипа - карточка рисует монограмму, это нормально |
| `categories` | Минимум одна из `CATEGORY_VALUES` |
| `tags` | Минимум один из `TAG_VALUES` |
| `peoples` | Минимум один из `tatar`, `bashkir`, `crimean-tatar` |

## Категории и теги

- Категория - чем проект является (`author`, `channel`, `media`, `language`,
  `lessons`, `graphics`, `community`). Тег - о чем он и в каком формате.
  Человек, который ведет телеграм-канал об истории, это
  `categories: ["author", "channel"]`, а не тег `blogger` вместо категории.
- Теги берутся только из реестра. Нужного слова нет - это отдельная правка
  `taxonomy.ts` (новый слуг, группа, метки ru и en), а не вольный текст в
  карточке: схема все равно уронит сборку.
- Разумный объем - 3-6 тегов. Пятнадцать тегов ломают AND-фильтр: карточка
  всплывает в выдаче, к которой не относится.
- `peoples` - не тег. Не дублировать народ тегом.

## EN-перевод

- **Новая карточка добавляется сразу с EN-переводом.** `bun run check:i18n`
  падает, если у id нет файла в `cards-en/` и его нет в
  `scripts/cards-i18n-baseline.json`.
- В `cards-en/<id>.md` только `name`, `description`, `facts`. Ни `url`, ни
  `logo`, ни `categories`, ни `tags`, ни `peoples` - они не зависят от языка
  и берутся из русского файла (`src/components/Catalog/localize.ts`).
- Число фактов совпадает с русским файлом, порядок тот же.
- `name` обычно не переводится, а транслитерируется так, как проект сам себя
  пишет латиницей.
- В baseline ничего не дописывать - список только сокращается.

## Текст

- Никаких «е» и длинных тире - только «е» и обычный дефис. Хук
  `scripts/hooks/no-yo-dash.mjs` заблокирует запись файла.
- Описание и факты - от третьего лица, без обращения к читателю.
- Не переписывать самоописание проекта дословно с рекламными оборотами:
  пересказать нейтрально.

## Перед тем как принять

```bash
bun run check:i18n   # у новой карточки есть EN-перевод
bun run verify       # схема, типы, сборка, SEO
```

Дальше глазами: карточка на `/`, на `/catalog/<category>` для каждой своей
категории, на `/en/`, и страница самого проекта.

Запуск проверок - по решению владельца репозитория, см. `starter-validation`.
