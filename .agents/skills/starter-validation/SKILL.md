# Definition of Done

Компилируется — не значит работает. Здесь уже был случай, когда `astro check`
показывал ноль ошибок, а `astro build` падал на отсутствующей зависимости.

## Обязательный минимум

```bash
bun run lint        # biome check . — линт и формат
bun run check       # astro check — типы .astro и .ts
bun run build       # реальная сборка
bun run check:seo   # build + проверка dist/
```

Или одной командой:

```bash
bun run verify
```

Красный `verify` = задача не сделана. Ошибки валидатора роняют команду,
предупреждения — только печатаются.

## Дополнительно — по типу изменений

**Тронул конфигурацию** (`main.config.ts`, `src/config/**`):
проверить, что валидатор ловит поломку — временно испортить значение и убедиться,
что сборка падает с внятным сообщением. Потом вернуть.

**Тронул фичу с флагом:** собрать в обоих состояниях и посмотреть `dist/`.

```bash
ls dist                       # артефакт есть / нет
grep -r "<артефакт>" dist     # висячих ссылок нет
```

**Тронул генерируемые файлы:** прочитать их целиком, не только проверить наличие.

```bash
cat dist/robots.txt dist/llms.txt dist/ai.txt dist/site.webmanifest
cat dist/index.md dist/en.md   # markdown-двойники dualmark — путь не всегда <route>/index.md
```

**Тронул `dualmarkStaticPages`/`llmsTxt.sections` в `astro.config.mjs`:** проверить
фактический путь markdown-двойника через `ls dist/*.md` — он не всегда
`<route>/index.md` (для `/en/` это `/en.md`), документация пакета неполна.

**Тронул `<head>` / SEO:** посмотреть собранный HTML, а не исходник.

```bash
grep -o '<meta[^>]*og:image[^>]*>' dist/index.html
```

**Тронул клиентский скрипт:** убедиться, что он попал в HTML и что событие,
на которое он подписан, вообще происходит. `astro:page-load` без `<ClientRouter />`
не срабатывает — на этом уже терялись все хиты аналитики.

## Проверять в `dist/`, а не в `astro dev`

Артефакты `robots.txt`, `ai.txt`, `llms.txt`, `site.webmanifest` и ключ IndexNow
генерируются на `astro:build:done` и в dev-сервере отсутствуют. Это ожидаемо.
Смотреть их через `bun run build` (+ `bun run preview` при необходимости).

## Внешние эффекты

IndexNow при `enabled: true` отправляет URL в реальный API. Для проверки
пайплайна ставить `dryRun: true` — список соберётся и залогируется без отправки.

## После проверок

Вернуть `main.config.ts` в стартовое состояние: все фичи выключены,
аналитика выключена, IndexNow выключен. Стартер отдаётся с безопасными дефолтами.
