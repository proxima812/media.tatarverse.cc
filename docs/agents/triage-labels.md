# Triage Labels

Скиллы говорят в терминах пяти канонических ролей триажа. Здесь эти роли
сопоставлены с реальными строками лейблов репозитория
`proxima812/media.tatarverse.cc`.

| Роль в скиллах    | Лейбл в нашем трекере | Значение                                              |
| ----------------- | --------------------- | ----------------------------------------------------- |
| `needs-triage`    | `needs-review`        | Заявка или баг ждет разбора человеком                 |
| `needs-info`      | `question`            | Ждем уточнений от автора заявки                       |
| `ready-for-agent` | `ready-for-agent`     | Задача описана полностью, можно отдать AFK-агенту     |
| `ready-for-human` | `ready-for-human`     | Требует ручной работы человека                        |
| `wontfix`         | `wontfix`             | Делать не будем                                       |

`needs-review`, `question` и `wontfix` в репозитории уже существуют.
`ready-for-agent` и `ready-for-human` нужно завести один раз:

```bash
gh label create ready-for-agent --description "Описано полностью, можно отдать агенту" --color 0e8a16
gh label create ready-for-human --description "Требует ручной работы человека" --color fbca04
```

## Лейблы автоматики - не трогать

Эти лейблы принадлежат воркфлоу в `.github/workflows/`, а не триажу.
`/triage` их не ставит, не снимает и не переиспользует как состояния:

| Лейбл             | Кто владеет                | Что делает                                                    |
| ----------------- | -------------------------- | ------------------------------------------------------------- |
| `card-submission` | `tally-submission.yml`     | Помечает issue, созданный из формы Tally                      |
| `draft-card`      | `draft-card-pr.yml`        | Триггер: постановка лейбла запускает сборку черновика PR       |
| `card-drafted`    | `draft-card-pr.yml`        | Черновик PR по этой заявке уже открыт                         |

`draft-card` особенно опасен: он не описывает состояние, а запускает
воркфлоу с записью в репозиторий. Ставить его вручную можно только
осознанно, по процедуре из `starter-pr-review`.

## Обычный путь заявки

`card-submission` + `needs-review` (автоматика) -> человек разбирает ->
либо `draft-card` (бот собирает черновик карточки, дальше
`starter-card-review`), либо `question` (нужны уточнения), либо `wontfix`.
