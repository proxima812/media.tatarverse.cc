## Метод и границы

- Начальные узлы: существующие карточки `Neurotatarlar`, `Bashkir Corpus`, `Apertium tat-bak`, `Qırımtatar TTS Datasets`, `Qırımtatar Tili`, `Lugat`, проекты Qirimca и языковые карточки каталога.
- Реальные ребра traversal: GitHub organization/owner → соседние репозитории; README/homepage → demo/dataset/model; corpus/tool → upstream Apertium, GiellaLT, DraCor, Hugging Face; каталог ресурсов → отдельный ресурс.
- Проверка: официальный GitHub API и страница primary repository; для части проектов - официальный demo/homepage или Hugging Face как вторичный источник. `pushed` ниже - значение GitHub API на дату прохода, а не обещание регулярной поддержки.
- В каталог допускаются только самостоятельные `language`, `lessons`, `media`, `channel`, `author`, `graphics`. Организации, фестивали и форумы использованы только как источники графа.
- География - место команды/институции, если оно очевидно из официального источника; иначе `online / not asserted`. Неподтвержденные города не выведены из домена или языка.

## Graph saturation notes

- **Qirimca / Qırımtatar Tili:** после переходов project page → GitHub owners → sibling repos появились клавиатура, POS dictionary, transliteration, TTS и детские словари. Дальнейшие репозитории преимущественно форки, issue trackers или студенческие заготовки; ветвь близка к насыщению.
- **Apertium / GiellaLT:** полезная зрелая ветвь дала monolingual packages и три translation/proofing nodes. Дальнейшее дробление на словари/файлы внутри package создало бы искусственные карточки; traversal остановлен.
- **Neurotatarlar / speech:** дала IS2AI, Tatar Speech Tools, ASR/TTS и ONNX deployment. Следующий слой в основном универсальные Whisper/MMS upstream, не тематические проекты; ветвь насыщена.
- **Corpora:** письменный/устный/драматический корпуса дают честно разные самостоятельные продукты. Tatoeba/OPUS/SIGMORPHON оставлены источниками, а не десятками карточек.
- **Dictionaries/transliteration:** обнаружено много маленьких repos. Qualified только имеющие ясное назначение, данные или live demo; учебные и пустые отклонены.
- **Events:** проверены типовые цепочки Сабантуй/форум → organizer/partners/media. Они в основном ведут к культурным организациям, которые текущая схема не позволяет назвать честно; новых подходящих developer/media products эта ветвь почти не дала.

- Сабантуи и всемирные молодежные форумы: organizer, partner, speaker и media-partner lists использованы как discovery edges; организации не внесены из-за schema mismatch.
- GitHub Search API и официальные organization/owner pages: `IS2AI`, `qirimca`, `prosvita`, `apertium`, `giellalt`, `dracor-org`, `LingConLab`, `neurotatarlar`, `Tatar-Tili-Tilsizgasi-Surasi`.
- Официальные project/demo surfaces: ISSAI Turkic ASR, GiellaLT docs, DraCor, GitHub Pages demos, Hugging Face Space Qırımtatar TTS.
- Developer/data families: corpora, TTS, ASR, translation pairs, morphological analyzers, proofing, dictionaries, keyboards, transliteration, speech-corpus mining.
