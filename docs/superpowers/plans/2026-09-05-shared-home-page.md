# Общая главная: английская повторяет русскую слово в слово

**Дата:** 2026-09-05
**Спека:** -

## Зачем

Русская и английская главные разошлись: разный набор блоков, разный порядок,
а `DepthDeck` есть только на английской. Посетитель `/en/` видит другую
страницу, а не ту же самую на своем языке. Нигде не записано, что так и
задумано, и любая правка главной означает две несинхронные правки.

После задачи главная одна: тот же набор блоков в том же порядке, отличается
только язык.

## Что меняем

- Создать: `src/components/pages/HomePage.astro` - тело главной, локаль пропом
- Создать: `src/components/pages/homeContent.ts` - тексты главной по локалям
  одним типизированным модулем
- Изменить: `src/pages/index.astro`, `src/pages/en/index.astro` - тонкие
  обертки по пять строк
- Порядок блоков - как на русской: LogoStack, MainTitle, SearchShowcase,
  Features, StatField, StepRail, StickyList, Quote, DepthDeck, LogoMarquee,
  InstFollows, FAQ
- `DepthDeck` встает на обе главные: компонент рабочий, просто русская
  страница его не показывала

Пять способов задать английский текст (словарь, дефолт пропа, объект во
фронтматтере страницы, таблица локалей внутри компонента, тернарник)
сводятся для главной к одному: `homeContent(locale)`.

## Чего не трогаем

- Дефолты пропов в самих компонентах (`FAQ`, `Features`, `InstFollows`) -
  это дефолты стартера, они остаются нейтральными. Главная передает свой
  контент явно, а не полагается на них.
- Русскую цитату в `main.config.ts`: `main.config.ts` остается единственным
  файлом, который правят под новый проект, поэтому русский вариант читается
  оттуда, а перевод лежит рядом с остальным английским текстом главной.
- `StepRail`, `StickyList`, `MainTitle`, `LogoMarquee`, `StatField` - у них
  свои встроенные таблицы локалей; это отдельная задача.
- URL: `/` и `/en/` остаются как есть, `markdownURL` считается по локали.

## Шаги

- [ ] `homeContent.ts` с русским и английским текстом
- [ ] `HomePage.astro` с порядком русской главной и DepthDeck
- [ ] Тонкие `index.astro` в обеих локалях
- [ ] Сверка собранных страниц

## Проверка

- `bun run test` и `bun run check` - без новых ошибок
- `bun run build`: набор html-файлов в `dist/` не изменился
- Число секций на `/` и `/en/` совпадает, и оба содержат DepthDeck
- Глазами: `/` и `/en/` рядом, блок за блоком

## Риски

- **Английский текст потеряется.** Он лежал во фронтматтере страницы; если
  ключ не перенести, блок молча покажет русский дефолт стартера. Ловится
  сверкой: на `/en/` не должно остаться русских слов.
- **DepthDeck на русской главной.** Компонент до сих пор рендерился только
  на английской, то есть на русских данных его никто не видел.
