# Поиск логотипов карточек

**Дата:** 2026-09-19
**Спека:** -

## Зачем

Находить изображения на официальных страницах карточек без logo, просматривать кандидатов и добавлять только выбранные изображения, не переписывая контент.

## Что меняем

- Создать `scripts/logos/logos.py`: scan, HTML-превью, экспорт выбора, apply с резервными копиями.
- Создать `scripts/logos/test_logos.py`: локальные проверки разбора, изображений и безопасной записи.
- Создать `scripts/logos/requirements.txt`: Pillow и PyYAML для отдельного Python-инструмента.
- Создать `scripts/logos/README.md`: запуск и ограничения.

## Чего не трогаем

Карточки и ассеты при разработке, EN-переводы, UI сайта, зависимости приложения. Рабочие отчеты сохраняем в игнорируемой `.cache/logo-discovery/`. Скрипт привязан к корню репозитория, а не cwd.

## Шаги

- [x] Добавить выбор в локальном HTML и применение с проверкой хешей.
- [x] Проверить на временном проекте и выполнить ограниченный scan реальных карточек без их изменения.

## Проверка

Python unittest без внешней сети; ограниченный реальный scan. Сборка сайта не требуется, поскольку сайт и карточки не меняются.

## Риски

Обложка может оказаться не логотипом: выбор только вручную. Соцсети могут блокировать доступ или возвращать общий бренд: такие результаты помечаются для проверки. SVG не растрируем; неподдерживаемые форматы отражаем в отчете. Существующие logo и файлы не перезаписываем.

Результат: 9 локальных тестов прошли. Реальный scan двух карточек нашел 2 кандидата; карточки и ассеты не менялись. Всего обнаружено 275 карточек без logo.
