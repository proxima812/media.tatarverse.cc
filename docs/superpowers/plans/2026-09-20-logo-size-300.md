# Оптимизация логотипов до 300 x 300

**Дата:** 2026-09-20
**Спека:** -

## Зачем

Унифицировать размеры и уменьшить вес исходных логотипов карточек. Пользователь уточнил область: все 195 PNG в папке logo.

## Что меняем

- `src/assets/images/logo/*.png`: 195 файлов, размер 300 x 300, сохранение пропорций, прозрачные поля вместо обрезки, PNG со сжатием палитры Sharp quality=95.

## Чего не трогаем

Карточки и пути logo, фотографии, иллюстрации, public, SVG, компоненты и настройки Astro. Существующая выдача WebP через Image остается прежней.

## Шаги

- [x] Сохранить исходники и хеши в `.cache/logo-resize-300/`.
- [x] Подготовить PNG через установленный Sharp, визуально проверить примеры и применить.
- [x] Проверить размеры всех файлов, целостность и типы проекта.

## Проверка

195 файлов должны иметь размер 300 x 300. Сравнить общий размер до и после, проверить PNG и резервные копии. `bun run check`; полную сборку не запускать.

## Риски

65 изображений меньше 300 пикселей: увеличение не добавляет исходной детализации. Сохраняем их исходники. Для прямоугольных изображений добавятся прозрачные поля.

Пробная обработка без сжатия палитры не уменьшила общий вес. Выбран PNG palette=true, quality=95; сравнение логотипов, текста и фотографий выполнено до замены.

Результат: 195 PNG размером 300 x 300. Вес: 13 662 918 -> 5 884 456 байт (-56.9%). Исходники и отчет: `.cache/logo-resize-300/2026-09-20T08-30-41.076Z/`.
