media.tatarverse is an open catalog of projects about the Tatar, Bashkir and
Crimean Tatar languages and cultures. Authors, channels, media outlets, language
platforms, lessons and graphics - collected in one place, each with a
description and a link to the original.

## Why it exists

There are many such projects, but they are scattered: a channel lives in
Telegram, a dictionary on its own domain, a course on a platform, an author in a
social network. You find half of them by accident, and a year later half of the
links are dead.

The catalog solves one problem: show what exists and lead you to the original.
It does not retell or replace anyone's content - every card links straight to
the project itself.

## What gets into the catalog

A project is included if it is **about the Tatar, Bashkir or Crimean Tatar
language and culture** and **publicly reachable** - there is a working link
anyone can use.

Each card describes one project: name, short description, three or four
verifiable facts, link, categories, tags and peoples. The facts are statements
you can check against the project itself, not marketing promises.

There are seven categories: channel, author, media, language project, lessons,
graphics, community. A project can sit in several at once - a language platform
with lessons goes into both.

What is not here: projects without public access, duplicates of the same project
on different platforms (the main one is used) and cards written as
advertisements.

## How the catalog works

The site is static, there is no database. Every card is a plain markdown file in
the [open repository](https://github.com/proxima812/media.tatarverse.cc), and
the build turns those files into pages. Three things follow from that:

- **The history is visible.** Any edit to a description can be traced in the
  commit history - who changed what and when.
- **Anyone can fix a mistake.** Every project page has a "Suggest an edit"
  link that opens the right file in the GitHub editor.
- **The catalog does not disappear with the server.** The data is files; it can
  be downloaded whole and hosted anywhere.

The catalog is bilingual: Russian is the source, English is a mirror. If a card
has no translation yet, the English version shows the Russian text - the project
stays visible instead of vanishing from the list.

Bookmarks ("Saved") are stored in your browser only. There are no accounts, and
the saved list is never sent anywhere.

## How to help

- **Add a project** - through the [form](/en/add) or a pull request.
- **Fix an inaccuracy** - with the "Suggest an edit" link on a project page. If a project
  moved, closed or is described wrongly, that is a bug in the catalog.
- **Translate a card into English** - translations are separate files, so they
  can be done one at a time.

## Related projects

## Questions and answers

### Found a mistake in a card - where do I write?

Whichever way suits you, they all reach us:

- **"Suggest an edit" on the project page** - the link at the bottom of that
  page opens that file in the GitHub editor. The shortest route if you have an
  account.
- **An issue in the repository** -
  [github.com/proxima812/media.tatarverse.cc/issues](https://github.com/proxima812/media.tatarverse.cc/issues).
- **A pull request** - if you want to send the corrected text right away.
- **Telegram** - [@the_tatarverse](https://t.me/the_tatarverse).
- **VK** - [the_tatarverse](https://vk.ru/the_tatarverse), **Instagram** -
  [@the_tatarverse](https://instagram.com/the_tatarverse), **Threads** -
  [@the_tatarverse](https://www.threads.com/@the_tatarverse).

A link to the project page and to the original source helps - then the fix
takes a minute.

### A project closed or moved - will the card be removed?

Moved - we fix the link. Closed - we remove the card: the catalog leads to live
projects, it is not an archive of dead links. Write to us any way listed above.

### I am the author and I do not want to be in the catalog

Write to us and we will remove the card, no explanation needed. More on the
"[Sources](/en/sources)" page.

### How long does a submission take?

Usually between an hour and a day. Every submission is moderated: we check the
link and the facts, add categories and tags, and rewrite the description if it
reads like an advertisement.

### Why might my submission be rejected?

Three common reasons: the project is not about the Tatar, Bashkir or Crimean
Tatar language and culture; it has no working public link; the submission
duplicates an existing card.

### Can I reuse the catalog data?

Yes. Card texts are under CC BY 4.0 with attribution, and the data sits as files
in the repository - no need to scrape the site. Project logos belong to their
owners, see "[Terms of use](/en/terms)".
