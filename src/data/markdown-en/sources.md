The catalog runs on open data and community contributions. This page explains
where things come from, who owns what, and how to fix it.

## Where the project data comes from

The name, description, facts and logo of every card are gathered from the
project's own public sources: its website, social media pages, app store listing,
public descriptions and coverage.

The rules we hold to:

- **Only what can be verified.** The three or four facts in a card are
  statements you can check against the project itself - not opinions, not
  advertising.
- **The project is the source of truth.** If its own description differs from
  ours, the project is right.
- **Data goes stale.** A project may move, close or change format. Please tell
  us - see below.

We are not an official representative of any listed project.

## How to check and correct

Every card is a separate file in the
[open repository](https://github.com/proxima812/media.tatarverse.cc): you can see
when it was added and what has been changed. Each project page has a "Suggest an
edit" link that opens that file in the GitHub editor.

## Logos and trademarks

Logos, names and other trademarks shown in the cards belong to their respective
owners. They are used in the catalog solely to identify the project (nominative
use) and do not imply partnership, sponsorship or endorsement by anyone.

Logos are stored as copies in the catalog's repository, so it does not
break when a project redesigns its site or an image disappears.

## Requesting a correction or removal

If you represent one of the listed projects and want to correct a description,
replace a logo or remove a card, write to us any of the ways under "Contact". We
handle such requests first and do not ask for a reason.
