## What this service is

media.tatarverse is an open, non-commercial catalog of projects about the Tatar,
Bashkir and Crimean Tatar languages and cultures: authors, channels, media
outlets, language platforms, lessons and graphics. We do not create or own these
projects - we only collect links and short descriptions in one place.

The catalog is not an official representative of any listed project unless the
card says so explicitly.

## Submitting and editing cards

You can add a project through the [form](/en/add) or a pull request in the
[repository](https://github.com/proxima812/media.tatarverse.cc). By sending a
submission or a PR you confirm that you are entitled to share that text and
agree to publish it under the catalog's license.

A submission from the form becomes a public issue in the repository - see the
"[Privacy Policy](/en/privacy)" for details.

We are not obliged to publish every submission: a card may be rejected or
rewritten - for instance if the description reads as advertising, the facts
cannot be verified, or the project is off-topic for the catalog.
